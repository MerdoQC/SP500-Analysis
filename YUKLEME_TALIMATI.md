# GitHub'a yükleme

1. Bu ZIP'i bilgisayarında aç.
2. Açılan `SP500-Analysis-Final` klasörünün **içindeki bütün dosya ve klasörleri** GitHub deposunun ana sayfasına sürükle.
3. Değişiklik mesajına `Rev 2.1 final site` yazıp **Commit changes** seç.
4. GitHub'da **Settings → Pages → Source → GitHub Actions** seç.
5. **Actions → GitHub Pages'e yayınla → Run workflow** seç.
6. Yayın adresi: `https://merdoqc.github.io/SP500-Analysis/`

Ziyaretçiler yalnızca siteyi görüntüler. Veri güncelleme iş akışını yalnızca depo sahibi çalıştırabilir.
